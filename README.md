# AURORA DJ Studio

Estúdio de áudio no navegador, criado para o repositório **dj**.

## O que já funciona

- Upload local de áudio com limite de 2 arquivos no plano Free.
- Visualizador em barras, órbita e onda.
- Ajustes de graves, agudos, sensibilidade e suavização.
- Reprodução, mute, fila da sessão e limpeza.
- Exportação local em WebM com limite de 2 exportações.
- Interface responsiva para celular e desktop.
- Fundo líquido que reage ao movimento do cursor.
- Áreas de Biblioteca, Visualizadores, Mixer, Presets, Exportações e Configurações.

## Integrações preparadas

- Google OAuth: preencher o Client ID público em `config.js` e conectar o callback no backend.
- IA: nenhum provedor é chamado nesta versão.
- Brevo: não utilizado.

Os arquivos de áudio são processados no navegador e não são enviados para um servidor por padrão.
